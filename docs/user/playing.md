# 连接、组卡与对局操作

本文的界面文字全部引用 `apps/desktop-client` 源码中的实际字符串。

## 首页

打开客户端后是首页，标题为 “Riftbound”，副标题为 “选择下方入口开始你的对局体验”。
左侧显示玩家名、连接状态（“已连接服务器” / “未连接服务器”）、当前房间、卡组数量；
对局进行中会出现“继续对局”。首页六个入口依次是：

| 入口 | 作用（源码描述） |
| --- | --- |
| 房间连接 | 连接服务器、创建或加入房间 |
| 卡组管理 | 编辑并保存本地卡组 |
| 对局回放 | 回看已结束的对局记录 |
| 个人信息管理 | 查看与修改个人资料 |
| 退出 | 退出当前会话并关闭桌面客户端 |
| 设置 | 调整客户端偏好与显示选项 |

> 截图占位（待本机视觉验证补图）：`docs/user/images/home.png` —— 首页六个入口与左侧状态栏。

## 连接服务器并创建 / 加入房间

1. 点击“房间连接”，展开“服务器设置”，在“服务地址”里填服务端的 WebSocket 地址。
   默认值是 `ws://127.0.0.1:8787`；也可以填 `http://` / `https://` 地址，客户端会分别
   归一化为 `ws://` / `wss://`，并自动补上 `/ws` 路径。
2. 点击“连接”。状态栏会显示“未连接”“连接中”“已连接”“重连中”或“已断开”。
3. 填写“昵称”（最长 24 个字符，与个人信息页的昵称上限一致）。
4. “创建新房间”里选择“对局规则”，三个选项与界面描述为：
   - 基础规则 —— “基础对局模式。”
   - 1v1 对局 —— “标准 1v1 对局，准备后即可在牌桌对战。”（默认选项）
   - 演示规则 —— “用于体验对战流程。”
   下方提示为：“部分卡牌效果尚未支持；可用操作以当前牌桌提示为准。”
5. 点击“创建房间”。把“房间号”发给对手。
6. 对手自己连接服务器后，在“加入已有房间”填“房间号”，点击“加入房间”。

> 截图占位（待本机视觉验证补图）：`docs/user/images/connect-room.png` —— 服务地址、昵称、创建与加入房间区域。

## 房间大厅

进入房间后是“房间大厅”。顶部“房间信息”显示“房间号”“规则”“状态”（等待中 / 对局中
/ 已结束），右侧有“同步房间事件”和“进入对局”（对局开始后才可用）。“玩家列表”为每位
玩家显示“已连接”或“未连接”、“已准备”或“未准备”、“卡组已提交”或“卡组未提交”；
你自己一行带“你”标记。

“卡组选择”区域可以选用本机保存的卡组；下方“准备与提交”区域有两个按钮：

- “提交当前卡组”：把当前卡组提交给服务端校验与登记。
- “准备开局” / “取消准备”：卡组提交确认后才可以准备；已准备时按钮变为“取消准备”。

卡组变更后需要重新提交，界面会提示“卡组已变更，请重新提交”。房间内已准备时，先
“取消准备”再导入或修改卡组。双方都准备好后房间状态变为“对局中”，此时可以点击
“进入对局”。（“演示规则”在第二名玩家加入时立即开局，不需要双方准备。）进入牌桌后，
“局内配置”里有“返回首页”与“返回房间”。

房间与牌桌都有聊天窗口。输入消息后按回车或点击“发送”即可，消息以服务器确认的记录
为准（客户端不会先显示本地回显）。单条消息最多 500 个字符。

> 截图占位（待本机视觉验证补图）：`docs/user/images/room-lobby.png` —— 房间信息、玩家列表、卡组选择、准备与提交。

## 组卡

从首页进入“卡组管理”。页面顶部显示“我的卡组”和“卡组总计 N 张 · 当前区域：<区域>”，
并提供“仓库服务地址”输入框与“重试”“校验卡组”按钮。

### 卡组区域

六个区域标签依次为主卡组、符文、传说、英雄、战场、备牌。切换区域后，用“组卡搜索”
（占位文字“搜索卡名或规则身份”）搜索并添加卡牌；结果列表显示“N 张已选 · M 个匹配结果”，
没有结果时显示“没有匹配的卡牌”。

### 卡组库

- “卡组名称”填写名称（最长 40 个字符），点击“保存为命名卡组”。
- 列表中的“载入”把某个命名卡组载入当前草稿；选中后可用“更新所选卡组”“删除所选”。
- 还没有保存的卡组时显示提示：“还没有保存的卡组。填写名称后点“保存为命名卡组”。”

### 导入 / 导出

“导入卡组”面板接受本应用导出的 JSON 或符合标准 schema 的卡组内容；文本框标签为
“粘贴卡组文件内容”，按钮为“导入卡组”；导出按钮为“导出当前卡组”，只读文本框标签为
“当前卡组 JSON”。导入不会在本地判定合法性，面板明确提示“导入后需提交服务端校验”。

### 合法性

本地保存只是草稿；“校验卡组”返回服务端结果才代表构筑合法性。校验通过显示“服务端校验
通过。”，否则面板逐条列出问题。房间内“已提交”同样以服务端结果为准。

> 截图占位（待本机视觉验证补图）：`docs/user/images/deck-builder.png` —— 卡组区域标签、搜索、卡组库与校验结果。

## 牌桌与对局操作

牌桌按卡垫上下镜像排列：“对手手牌”“对手基地”“中央战场”（两个共享战场并排）
“我方基地”“手牌”等区域有固定位置；对手手牌只显示背面与数量。点击卡牌可查看大图，
关闭按钮为“关闭大图” / “关闭”。

右侧“时点提示”区域会显示当前窗口，例如“准备阶段”“调度阶段”“主阶段”“对决焦点”
“可连锁时点”“正在支付施放费用”“等待玩家选择”“正在完成出牌”“等待对手响应”
“战斗伤害分配”“战斗进行中”“结算中”“等待规则处理”“对局结束”。

**可执行操作以“动作与选择”面板中启用的按钮为准。** 面板标题为“动作与选择”，列表为
“可用动作”；没有动作时显示“当前无可用动作”，牌桌上另有提示“当前没有可用操作”。
按钮文字由服务端投影给出，实际标签包括：

| 局面 | 界面上的动作 |
| --- | --- |
| 调度阶段 | “选择重调手牌（最多 2 张）”；本轮你调度时提示“轮到你调度：选择 0–2 张手牌后确认”，点击“确认调度（已选 N）”。 |
| 主阶段 | 按当前可用动作执行；常见标签有“移动”“结束回合”，法术窗口为“施放法术”。 |
| 连锁 / 优先权 | “让过优先权”“让过焦点”“施放法术”等，以面板实际启用项为准。 |
| 战斗 | “分配战斗伤害”；按提示填写每个目标的伤害后“确认”。 |
| 额外费用 | “选择额外费用”；选项确认后按“本次支付”的合计筹资并支付。 |
| 资源 | 展开资源区后按来源操作：“横置<域>符文：+1 能量”“回收<域>符文：+1 <域>符能”“横置并消灭金币：+1 任意符能”“支付待结算费用”。 |

资源池按服务端投影显示能量、各域符能与通用符能，零值也会显示。资源区给出提醒：“余额在
本回合保留，回合结束时清空”“主阶段开始时同样清空资源池”“仅展示，不会自动扣减”；
真正的扣减由服务器规则引擎执行。遇到尚未接入的效果时，牌桌停在“等待规则处理”，
不会猜测结算。

### 局内配置、认输与退出

牌桌的“局内配置”里有“显示与对局设置”：卡牌尺寸（小 / 中 / 大）、“减少动态效果”
“显示卡牌名称”“认输需要二次确认”，以及“返回首页”“返回房间”。认输按钮为“认输”；
开启二次确认时需要再点“确认认输”，或点“取消”返回。

首页或外壳上的“退出”会断开连接并关闭桌面客户端（浏览器预览环境会回到首页）。

## 回放查看

对局中点击“保存回放”，把本机当前视角已记录的投影帧保存到本机回放库。然后从首页进入
“对局回放”：

- 左侧“已保存对局”列出记录，每条显示标题、“房间 <roomId> · N 帧”和保存时间；可“删除”。
- 选中一条后，“画面时间轴”提供“上一帧”“下一帧”“播放” / “暂停”，以及“画面范围”
  滑杆和“第 i / N 帧”计数。
- “当前帧摘要”显示阶段、回合、回合玩家、优先权、可见操作、视角。
- “展开牌桌”把牌桌占满窗口，工具栏保留翻帧、播放/暂停与“返回时间轴（Esc）”；
  展开状态下先按 Esc 只关闭卡牌大图，再按 Esc 才退出展开。

回放只读：“回放只读：播放与翻帧不会发送任何对局指令。”单次最多记录 300 帧，本机
最多保存 10 份，达到上限时自动丢弃最旧的一份。回放只包含服务端发给当前视角的公开投影，
对手手牌仍只显示背面与数量。

> 截图占位（待本机视觉验证补图）：`docs/user/images/replay.png` —— 已保存对局、画面时间轴与当前帧摘要。

## 个人信息与设置

“个人信息管理”里可修改昵称（1–24 个字符）、从四个预设图案中选头像（符文 / 利刃 /
星辰 / 新叶）、填写个人简介（最多 160 个字符），点击“保存到本机”。这些资料只保存在
本机存储，没有账号后端，也不会上传；在房间内修改昵称只对下一次进入房间生效。

“设置”只影响本机显示，不改变对局规则；选项与“局内配置”一致：卡牌尺寸、减少动态效果、
显示卡牌名称、认输需要二次确认。

服务端的启动与地址配置见 [server.md](server.md)；安装与校验安装包见 [install.md](install.md)；
常见问题见 [faq.md](faq.md)。
