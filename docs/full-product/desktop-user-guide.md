# 桌面客户端操作指南

适用范围：当前 V2 独立房间与牌桌；旧界面差异单列在“旧房间界面”。

首页提供六个入口：**房间连接、卡组管理、对局回放、个人信息管理、退出、设置**。进行中的对局可通过“继续对局”返回；其他页面的顶栏会提供“返回对局”。页面切换本身不会结束对局。

## 连接与开局

以下流程使用协议 V2 独立房间。

1. 从首页打开“房间连接”，点击“使用协议 v2 独立房间”。
2. 在“V2 服务地址”填写服务端地址并点击表单里的“连接”。协议层默认地址是 `ws://127.0.0.1:8787/ws`；输入 `ws://127.0.0.1:8787` 或 `http://127.0.0.1:8787` 也会规范化为该路径。页面显示“已连接”后，“连接 V2 服务”入口会消失。
3. 在“玩家名”填写昵称。一人点击“创建 1v1 房间”后，把“房间”旁的 8 位房间号告诉另一人；另一人在“房间号”中填写并点击“加入房间”。
4. 双方在“M1 预组”下拉中选择 `rumble-sfd` 或 `fiora-sfd`，分别点击“提交预组牌组”。本席提交成功后该按钮停用，再点击“准备”。双方提交并准备后，服务端依次开放换牌窗口。
5. 轮到换牌时，在“我的手牌”中选择至多 2 张。未选择时按钮为“保留起手”；选中后显示 `换掉 N 张`。未轮到的一方显示“等待服务端开放你的换牌窗口。”。
6. 双方确认换牌后开始正式对局。可通过首页的“继续对局”或顶部导航的“对局”回到牌桌。

同一 origin 的标签页共享本地会话；要模拟两名玩家，请使用独立浏览器 profile、两个已提供的不同端口页面，或一个原生 App 加一个浏览器窗口。V2 房厅显示的房间状态与房间版本来自服务端；操作以回执和投影中的状态号、事件号为准。

旧房间/对局界面的聊天窗口仍提供输入框与“发送”按钮。V2 牌桌页面源码不提供同样的聊天入口。消息是否出现以服务器确认的记录为准。

## 管理卡组

从“卡组管理”进入，按主卡组、符文、传说、英雄、战场、备牌区域搜索并添加卡牌。填写卡组名称后保存；也可载入、更新或删除已有卡组。

“导入卡组”接受应用导出的 JSON；“导出当前卡组”提供可复制的 JSON。本地保存是草稿，构筑是否合法以“校验卡组”返回的服务端结果为准。如果正在旧房厅等待，先取消准备再导入或修改。

M1 beta 的 V2 开局使用“M1 预组”下拉，不从卡组库选择任意构筑。

## 牌桌与当前时点

V2 牌桌顶部显示阶段、回合、连接状态、投影状态号与事件号。其下依次显示双方玩家状态、“对手手牌”（仅数量）、对手基地、共享战场、我方基地、对手公开符文和“我的手牌”。再往下是操作和选择区域。隐藏牌面不会由客户端自行展开。

**可执行操作以当前启用的按钮与服务端回执为准。**

- 在“我的手牌”点牌，按“出牌”区公布的“永久物落点”、目标要求和候选对象选择，再点“打出手牌”。没有服务端候选时不要猜测对象；无落点或无目标的牌按当前投影直接显示。
- 在“符文”区点“取能量”或“取 Power”。能量与 Power 数值来自当前玩家投影；已横置或缺少服务端对象身份的符文不能操作。
- 在“移动”中选择一个可移动单位和服务端公布的目的地，再点“移动单位”。
- 在“对局操作”中点“Pass”让过当前允许的优先权，或点“结束回合”。
- 在“战斗”中点“推进”，继续当前由服务端开放的规则任务。伤害分配窗口出现时，按当前分配者投影显示的公开目标填写金额，合计等于页面预算后点“提交战斗伤害”。等待另一方时显示“等待对方分配伤害”。
- “选择请求”可能要求可选效果、模式、对象、排序或数值。按页面的可选数量与顺序提示操作，再点“提交选择”；“接受”和“拒绝”只用于可选效果。候选缺失时界面会等待服务端投影。
- 点“认输”后必须再点“确认认输”，或点“取消”退出确认。“链 / 优先权”显示链状态、阶段、窗口、Priority 与 Focus；“对局日志”按事件号显示服务端事件。

命令发出后，顶部显示“正在处理…请等待服务端回执；命令完成前，重复操作已停用。”。命令被拒绝时显示“命令 … 未执行：<原因>”；服务端没有提供原因时显示“服务端未提供拒绝原因。”。遇到尚未接入的卡牌效果时保持“等待规则处理”，不要手工改状态或猜测结算。

## 旧房间界面

V2 页面左上方的“切换回旧房间界面”仍可打开旧房厅。旧房厅保留“服务器设置”“服务地址”“连接”，并可选择“基础规则”“1v1 对局”“演示规则”。进入房间后会看到“提交当前卡组”，未准备时按钮为“准备开局”；已准备时为“取消准备”。旧对局界面的切换按钮文案是“使用协议 v2 对局界面”或“切换回旧对局界面”，与房厅按钮不同。

旧界面的“确认调度（已选 N）”及卡垫交互不是本文所述的 V2 M1 流程。验收时应明确当前使用哪一套界面，不要把旧房厅行为写成 V2 预组流程的已完成能力。

## 局内配置与回放

V2 对局页顶部的“显示与对局设置”提供“卡牌尺寸”“减少动态效果”“显示卡牌名称”和“认输需要二次确认”，并提供“返回首页”和“返回房间”。这些设置只影响本机。

当前源码中仍有“保存回放”按钮，但它只随旧 Duel 牌桌渲染，且以旧投影决定是否可用；V2 牌桌没有独立的保存入口。V2 源码会捕获带终止状态的本机投影，回放页面也可显示“协议 v2”记录，但这一捕获没有把保存操作暴露到 V2 牌桌，完整产品入口仍需独立验收。

进入“对局回放”后，在左侧“已保存对局”里点击一条记录，用上一帧、下一帧、时间轴或播放按钮查看。回放只读，不发送对局命令，也不会显示仅对手可见的信息。旧 Duel 回放单次最多记录 300 帧；本机最多保存 10 份。

窗口小、不想先滚过记录列表和摘要时，点击右上角“展开牌桌”。牌桌会占满整个窗口，上方只留一行紧凑工具栏：上一帧、下一帧、播放/暂停、当前帧位置（第几帧 / 共几帧），以及“返回时间轴（Esc）”。点击“返回时间轴”或按 Esc 都会退出，并保留同一记录、同一帧。展开状态下若先打开卡牌大图，第一次按 Esc 只关闭大图，第二次按 Esc 才退出。只有选中了含有画面的记录时才会出现“展开牌桌”。对手手牌在回放中仍只显示背面和数量。

## 个人信息、设置与退出

“个人信息管理”可修改昵称、选择预设头像和填写简介，再点击“保存到本机”。在房间内修改昵称，对下一次进入房间生效。“设置”中的显示偏好只影响本机，不改变对局规则。

点击“退出”会断开连接并关闭桌面客户端；浏览器预览环境会回到首页。房间能否在服务器重启后恢复，取决于服务器是否启用持久化存储，并以恢复结果和服务端日志为准。
