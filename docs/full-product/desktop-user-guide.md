# 桌面客户端操作指南

首页提供六个入口：**房间连接、卡组管理、对局回放、个人信息管理、退出、设置**。
进行中的对局可通过“继续对局”返回；返回首页或房间只切换页面。

## 连接与开局

1. 打开“房间连接”，展开“服务器设置”，填写服务地址并连接。默认地址为
   `ws://127.0.0.1:8787`；如果服务器不在本机默认端口，改成实际的地址和端口即可。
2. 填写昵称。创建房间时选择大规则：基础规则、1v1 对局或演示规则；加入房间时填写房间号。
   房间连接页面不要求选择地区或赛事。
3. 在房间大厅选择已保存的卡组，点击“提交当前卡组”。确认提交成功后点击“准备开局”。
   玩家列表显示双方的连接、卡组提交和准备状态；双方准备后进入牌桌。
4. 卡组变更后需要重新提交。房间等待期间可以取消准备并换卡组。
5. 轮到调度手牌时选择 0–2 张，点击“确认调度”；对方操作时显示等待提示。

房间和牌桌都有聊天窗口。输入消息后按回车或点击“发送”，消息以服务器确认的记录为准。

## 管理卡组

从“卡组管理”进入，按主卡组、符文、传说、英雄、战场、备牌区域搜索并添加卡牌。
填写卡组名称后保存；也可载入、更新或删除已有卡组。

“导入卡组”接受应用导出的 JSON；“导出当前卡组”提供可复制的 JSON。
本地保存是草稿，构筑是否合法以“校验卡组”返回的服务端结果为准。
房间内已准备时，先取消准备再导入或修改。

## 牌桌与当前时点

牌桌按卡垫上下镜像排列：顶部是对手的手牌背面及数量，其次是对手符文排和基地；
中央并排放置两个共享战场；下方是我方基地、符文排和自己的手牌。
传说与英雄、主牌堆、符文库和弃牌区有固定位置，双方位置互为镜像。
单位和装备放在基地或所属战场，同一战场上的单位按当前控制者分组。
卡多时可在对应区域内滚动；基地两侧的左右按钮只翻看基地中的卡片。
点击卡牌图片可以查看大图。对手手牌只显示背面，旁观者看不到任何一方的隐藏牌面。

右侧时点提示区显示主阶段、对决焦点、战斗伤害分配、可连锁时点、费用支付、
等待对手或等待规则处理等状态。**可执行操作以右侧动作面板中启用的按钮为准。**

- 主阶段可按当前启用动作出牌、移动和结束回合。
- 对决焦点交给你时，可以执行当前允许的操作或让过焦点。
- 连锁窗口中，当前允许使用的牌会出现在动作面板；可以追加连锁或让过优先权。
- 轮到战斗伤害分配时，按显示的预算和目标分配伤害，再提交。
- 遇到尚未接入的卡牌效果时，界面会停在“等待规则处理”，不会猜测结算，也不要求你
  手动改状态；这类效果暂时无法继续自动结算。

双方符文区右侧各显示当前能量、各自传说的两种领域符能和通用符能，零值也显示。
领域来自与对局版本一致的传说卡牌目录；数字来自服务端对应玩家的资源池，
不会按符文张数推算。目录尚未加载时不猜测领域。
右侧资源操作区保留余额概览和筹资按钮；按钮只有在轮到你能操作、且当前时点允许时才会启用。
展开详情后，按牌桌列出的来源（符文或金币）获取资源。

如果一张牌带有可选额外费用，动作面板会先在“额外费用”提示里让你选择要支付还是不支付，
选定后点击确认。牌桌会列出本体费用和所选额外费用的合计，按提示筹齐资源后再支付。
选择“不支付”仍需支付本体费用；所选额外费用被减到 0 时，完成费用流程后仍保留支付该项的选择。

待支付摘要本身不会扣减余额，真正的扣减由服务器规则引擎执行。资源、伤害、分数和控制权
都由规则引擎自动结算；当前可执行操作以右侧动作面板中启用的按钮为准。

## 局内配置与回放

“局内配置”提供卡牌尺寸、减少动态效果、显示卡牌名称等本机偏好，以及返回首页、返回房间。
认输按钮只在当前对局提供此操作时出现，并遵循设置中的二次确认选项。

点击“保存回放”保存本机当前视角已记录的画面。然后从首页进入“对局回放”，在左侧
“已保存对局”里点击一条记录，用上一帧、下一帧、时间轴或播放按钮查看。回放只读，
不发送对局命令，也不会显示仅对手可见的信息。单次最多记录 300 帧，本机最多保存 10 份。

窗口小、不想先滚过记录列表和摘要时，点击右上角“展开牌桌”，牌桌会占满整个窗口，上方
只留一行紧凑工具栏：上一帧、下一帧、播放/暂停、当前帧位置（第几帧 / 共几帧），
以及“返回时间轴（Esc）”。展开只改变查看方式，不会移动当前画面，也不会改动所选
记录或帧；点击“返回时间轴”或按 Esc 都会退出，退出后仍停在同一记录、同一帧，键盘焦点回到“展开牌桌”。若在展开
状态下先点开一张卡牌的大图，第一次按 Esc 只关闭卡牌大图，第二次按 Esc 才退出展开牌桌。

只有选中了含有画面的记录时才会出现“展开牌桌”。对手手牌在回放中仍只显示背面和数量。

## 个人信息、设置与退出

“个人信息管理”可修改昵称、选择预设头像和填写简介，再点击“保存到本机”。
在房间内修改昵称，对下一次进入房间生效。
“设置”中的显示偏好只影响本机，不改变对局规则。

点击“退出”会断开连接并关闭桌面客户端；浏览器预览环境会回到首页。
房间能否在服务器重启后恢复，取决于服务器是否启用持久化存储。
